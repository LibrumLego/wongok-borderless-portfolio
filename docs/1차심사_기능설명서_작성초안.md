# 2026 관광데이터 활용 공모전 1차 심사 제출 초안

> 이 문서는 제출 내용을 정리하기 위한 작업본입니다. 최종 제출은 운영사무국이 제공한 **기능설명서 양식**에 그대로 옮겨 PDF로 내보냅니다. 서비스 키·개인정보·테스트용 비밀번호는 이 저장소에 기록하지 않습니다.

## 서비스 및 테스트 정보

| 항목 | 제출 기입안 |
| --- | --- |
| 서비스명 | 원곡 보더리스 (Wongok Borderless) |
| 서비스 주소 | https://wongok-borderless.vercel.app |
| 서비스 목적 | 안산 원곡동 다문화특구의 음식·문화·체험 장소를 6개 언어로 탐색하고, 개인 맞춤 동선과 현장 스탬프 경험으로 연결하는 지역 관광 웹 서비스 |

## 한국관광공사 OpenAPI 활용 정보

| 구분 | 실제 활용 방식 |
| --- | --- |
| 활용 API | TourAPI 4.0 |
| 호출 구조 | 브라우저는 `/api/tour`만 호출하고, 서버 프록시가 OpenAPI를 호출합니다. 서비스 키는 서버 환경 변수에만 보관합니다. |
| 지역·선별 목록 | `areaBasedList2`로 안산 연계 관광지를 조회하고 서비스 목적에 맞는 선별 목록을 구성합니다. |
| 거리순 추천 | `locationBasedList2`로 원곡동 중심 반경 내 장소를 조회해 실제 거리순으로 표시합니다. |
| 키워드·거리 소개 | `searchKeyword2`로 다문화음식거리 관련 정보를 조회합니다. |
| 상세 화면 | `detailCommon2`, `detailIntro2`, `detailImage2`를 결합해 개요·이용 정보·추가 이미지를 제공합니다. |
| 실시간성 | 외부 API 응답은 안정적인 서비스 제공을 위해 최대 30분 캐시하며, 캐시 만료 후 다시 OpenAPI에서 갱신합니다. |
| 키 제출 | 공모전 시스템에는 운영 계정의 인코딩 키와 디코딩 키를 모두 직접 입력합니다. 이 문서·GitHub에는 절대 기재하지 않습니다. |

## 핵심 기능 설명 (최대 5개)

### 1. 6개 언어 장소 탐색·통합 검색

- 사용자 문제: 원곡동을 처음 방문한 외국인도 음식, 국가, 체험 목적에 따라 장소를 찾기 어렵습니다.
- 기능: 한국어·영어·중국어·일본어·러시아어·인도네시아어 UI에서 상호, 번역명, 음식 태그, 설명을 함께 검색하고 음식 계열·거리 필터를 적용합니다.
- 입력/처리/결과: 검색어·필터 입력 → 다국어 장소 사전 전체에서 일치어 탐색 → 지도 마커와 결과 카드에 동일한 결과 표시.
- 심사 시연: 영어로 `halal` 검색 → 결과 카드 확인 → 장소 상세 화면 이동.

```text
사용자 검색어/필터 → 다국어 검색어 확장 → 장소 목록 필터링 → 지도·카드 동시 갱신
```

### 2. 선택 언어 기반 AI 관광 가이드

- 사용자 문제: 방문 목적을 문장으로 말해도 믿을 수 있는 범위 안에서 추천을 받아야 합니다.
- 기능: 선택 언어로 질문을 받고, 서비스에 검증 등록된 장소 데이터만 컨텍스트로 전달해 최대 3곳을 추천합니다.
- 안전장치: 존재하지 않는 장소·영업시간·가격·평점을 만들어 내지 않으며, API 키는 서버 환경 변수로만 처리합니다. 요청 크기·동일 출처·요청 빈도도 서버에서 제한합니다.
- 심사 시연: 영어 AI 가이드에서 `Any halal places?` 질문 → 영어 답변과 장소 카드 확인 → `Add to course` 선택.

```text
자연어 질문 + 현재 언어 → 등록 장소 후보 선별 → AI 응답/장소 ID 검증 → 현지화 카드 표시
```

### 3. 저장 장소 기반 도보 코스 만들기

- 사용자 문제: 추천을 받은 뒤 방문 순서와 이동 부담을 한눈에 정리하기 어렵습니다.
- 기능: AI 추천 카드 또는 장소 카드에서 저장한 장소를 지도 화면의 `내 코스`로 모아, 안산역 출발 및 이전 지점 기준 도보 시간·거리로 보여줍니다.
- 심사 시연: AI 결과에서 한 장소를 코스에 추가 → 지도 화면에서 `Saved 1` 및 `내 코스` 확인.

```text
장소 저장 → 브라우저 저장소에 중복 없이 기록 → 좌표 간 거리 계산 → 순서별 도보 안내 표시
```

### 4. 현장 GPS·퀴즈 스탬프와 QR 기기 전환

- 사용자 문제: 단순 조회를 실제 거리 방문과 문화 체험으로 연결할 장치가 필요합니다.
- 기능: 스탬프 대상 장소의 반경 안에서 GPS 인증을 하고, 현장 확인 퀴즈를 통과하면 스탬프를 수집합니다. PC에서는 현재 장소 페이지로 연결되는 QR을 제공해 휴대폰에서 이어서 인증할 수 있습니다.
- 유의: 위치 권한은 이 기능을 직접 실행할 때만 요청하며, 권한을 거부해도 다른 탐색·추천·코스 기능은 계속 이용할 수 있습니다.

```text
장소 상세 → QR/휴대폰 전환 또는 GPS 권한 → 반경 검증·현장 퀴즈 → 스탬프 저장 → 투어 진행도 갱신
```

### 5. 공공 관광데이터 실시간 연계

- 사용자 문제: 원곡동 방문 뒤 이어 갈 안산의 관광지·문화시설 정보를 최신 데이터로 확인하기 어렵습니다.
- 기능: 서버 프록시가 TourAPI 4.0의 지역·위치·상세·이미지 데이터를 조회해 홈의 안산 연계 장소, 거리순 목록, 상세 모달에 표시합니다.
- 보안/안정성: 키는 클라이언트에 노출하지 않고, 입력값 화이트리스트·속도 제한·오류 일반화·캐시를 적용합니다.
- 심사 시연: 홈 하단의 안산 연계 장소 탭 → `가까운 순` → 카드 선택 → 상세 정보 확인.

```text
홈 화면 요청 → /api/tour 서버 프록시 → TourAPI 4.0 → 정제·캐시 → 카드/상세 정보 표시
```
