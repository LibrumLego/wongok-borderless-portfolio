## 중복 마커 처리

누산따라·칸티푸르처럼 같은 건물의 서로 다른 층에 있는 장소는 좌표가 같아도 오류가 아니다. 원본 좌표는 그대로 보존하고, 지도 화면에서 2m 이내의 마커만 실제 지점을 중심으로 4m 펼쳐 모든 장소를 선택할 수 있게 했다.

## 모바일 확인

- 360×800 및 390×844 화면에서 가로 넘침 없음
- 검색 결과가 1곳이면 해당 장소를 지도 중심에 자동 배치
- 마커 선택 카드와 상세 이동 버튼이 하단 내비게이션에 가려지지 않음
- 레표시카 검색 → 마커 선택 → 상세 화면 → 네이버 장소 링크 연결 확인
