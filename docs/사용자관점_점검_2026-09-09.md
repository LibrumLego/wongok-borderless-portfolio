기준 커밋: 0032886 (중복 즐겨찾기 키 경고 방지). 깨끗한 master에 fast-forward로 반영했다.

## 재현 가능한 검증

`npm run test:favorites`: 실사용 Zustand persist를 메모리 저장소에서 실행한다. 사용자 브라우저 저장소는 건드리지 않는다. 신규 방문, null, 잘못된 ids, 중복 ID, 빈 ID, 저장된 함수 필드 오염, 추가·토글·삭제·전체 해제를 검사한다.

`npm run verify`: 린트·타입·프로덕션 빌드.

`npm run smoke:production`: 주요 진입 페이지·52개 장소 상세·관광 데이터 응답. AI 실제 답변이나 현장 GPS 인증까지 검증하는 테스트는 아니다.

## 남은 평가

- 홈의 네이비·주황과 여권 콘셉트는 통일감이 있다. 다만 장식보다 실사 사진과 핵심 정보의 비중을 높이는 것이 다음 우선순위다.
- 대표 사진이 없는 장소는 여전히 존재한다. 사진 수를 늘리기 위해 다른 가게 사진을 섞어서는 안 된다.
- 기존 장소의 모든 메뉴·할랄 표기·운영 상태를 이번에 재조사한 것은 아니다. 제출 전 원문 근거와 재확인이 필요하다.
- 외부 지도·사진 서비스와 현장 GPS는 별도 의존성이다. 브라우저 크기 검사는 실제 Android/iOS 기기 검사를 대체하지 않는다.
- 기존 보안 경고는 이번 UX 수정 범위에서 해결했다고 주장하지 않는다.
