# 원곡 보더리스 QA 및 심사 운영 체크리스트

## 현재 자동 점검

| 구분 | 실행 방법 | 확인 내용 |
| --- | --- | --- |
| 코드 품질 | `npm run verify` | ESLint, TypeScript, Next.js 프로덕션 빌드 |
| 키 노출 | `npm run check:secrets` | 커밋 대상 API 키 패턴 검사 |
| 운영 스모크 | `npm run smoke:production` | 홈·지도·AI·코스·스탬프와 등록된 49개 장소 상세의 HTTP 응답, 로그인 없는 접근, TourAPI 프록시, 금지 제공기관 표기 |
| 선택 AI 점검 | `SMOKE_CHAT=1 npm run smoke:production` | 영어 질문 1건과 추천 장소 ID 응답. API 비용이 발생하므로 수동 실행만 권장 |

GitHub Actions는 모든 push/PR에서 코드 검증을, 매주 월요일과 수동 실행에서 운영 스모크 점검을 수행한다.

## 심사위원 5분 시연 순서

1. 홈에서 언어를 영어로 바꾸고 `halal`을 검색한다.
2. 지도 결과에서 한 장소를 열어 번역명·원래 간판명·길찾기 링크를 확인한다.
3. AI 가이드에 `Any halal places?`를 입력하고 추천 카드에서 `Add to course`를 누른다.
4. 지도 화면에서 저장 장소와 안산역 출발 도보 동선을 확인하고, 필요 없는 장소는 `×`로 제거한다.
5. 스탬프 대상 장소 상세에서 QR 기반 휴대폰 전환과 GPS 현장 인증 흐름을 설명한다.
6. 홈 하단의 안산 연계 장소에서 거리순 목록과 상세 정보를 열어 공공관광 데이터 연계를 보여준다.

## 실기기·현장 확인 (팀 담당)

- [ ] iOS Safari와 Android Chrome에서 GPS 권한 허용·거부·시간초과 문구 확인
- [ ] 현장 반경 안/밖에서 스탬프와 퀴즈 흐름 확인
- [ ] QR을 실제 휴대폰 카메라로 스캔해 같은 장소 페이지가 열리는지 확인
- [ ] 외부 지도 링크, 전화 링크, 긴 주소가 정상 동작하는지 확인
- [ ] 한국어·영어·중국어·일본어·러시아어·인도네시아어별 홈/지도/AI 첫 화면 확인
- [ ] 사진·영업정보·연락처는 현장 또는 공식 채널 기준으로만 보정
- [ ] 식당별 사진이 없으면 공통 대체 비주얼이 표시되는지, 다른 식당 사진이 섞이지 않는지 확인
